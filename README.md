# Pig (Soft Reset Project)

Welcome to the start of our Dice Game Project!

This lesson is a **soft reset** — we review important JavaScript basics that we’ll need when we eventually build the full "Pig" dice game.

---

## Topics Covered:

- `let` and `const` variable declarations
- Re-assigning variables (`let`) and understanding immutability (`const`)
- Basic Data Types (Strings, Numbers, Arrays, Objects)
- Writing simple `if` and `if/else` statements
- Practicing comparison operators (`===`)
- Using `.classList.toggle()` to dynamically change an element’s class
- Hooking up a button with `addEventListener`
- A simple starting point for dice game logic (`if diceRolled === 1`, etc.)

---

## What's in this project:

- **HTML**: Structure for a player card and toggle button
- **CSS**: Styling for the player card, including an `.active` class
- **JavaScript**:  
  - Declare and re-assign variables
  - Handle button click events
  - Add/remove CSS classes dynamically
  - Write simple control flow (if/else)

---

## Skills Being Built:

- DOM Selection (`querySelector`)
- Adding/removing classes
- Updating the console with logs
- Thinking through logic flow using `if` and `else`
- Preparing foundation for future features like rolling dice, switching players, winning conditions, etc.

---

> This is the foundation for our bigger "Pig" game coming soon.  
> We’re focusing on mastering the **small pieces first**, so the full project will feel easy and fun!
